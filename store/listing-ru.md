# Legion 3D — город «Легиона» от первого лица

**Краткое описание:** Неофициальный 3D-режим для игры «Легион»: гуляй по городу, встречай игроков, исследуй лавки и шахту.

## Полное описание

Прогуляйся по ночному городу игры «Легион» на play.multidonate.ru: от первого или третьего лица, с другими игроками, их обликами и сообщениями над головами. Исследуй 3D-лавки и шахту; открывай снаряжение, сумку, карту и журнал прямо в игре. Настрой качество изображения под компьютер. Чат и игровые действия проходят через обычный клиент сайта.

Управление: WASD — идти, Shift — бежать, Space — прыгать, мышь — осматриваться, V — камера, E — действие, Tab — меню, Enter — чат, F8 — вернуться к классическому сайту. Для работы открой страницу канала `https://play.multidonate.ru/c/<канал>/` и войди в игру обычным способом; Chrome 111+.

**Важно:** это неофициальный проект, не связанный с разработчиками игры «Легион» или MultiDonate. Расширение не просит разрешений Chrome; действует только на страницах каналов игры. Оно не собирает данные, не использует аналитику и хранит настройки локально. [Политика конфиденциальности](https://github.com/ascorblack/legion-3d/blob/main/docs/PRIVACY.md).

- Категория: Fun (Развлечения).
- Единственная цель: добавить к сайту игры «Легион» необязательный 3D-режим с игровым интерфейсом.
- Обоснование доступа к сайту: `https://play.multidonate.ru/c/*` — только здесь открыт игровой «Город»; два локальных скрипта показывают 3D и читают данные текущей страницы для синхронизации игрового состояния. Другие сайты не затрагиваются.
- Удалённый код: нет; весь исполняемый код и графика поставляются в архиве расширения.
- Data usage / использование данных: данные пользователей не собираются, не продаются, не передаются; настройки остаются в localStorage сайта. Игровые данные обрабатываются локально на странице, а обычный клиент сайта общается с серверами игры.
